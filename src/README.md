# d77void Docs

This is the community documentation of **d77void**: Void Linux, with runit and
without systemd, ready to use with one of many window managers and desktops,
each with its own configuration already in place.

These pages explain what each variant brings and **where to change things**:
keyboard shortcuts, wallpaper, bar, autostart and the rest. Every detail is
checked against the files the ISOs are built from.

## Where to start

- New to d77void? Read [What d77void is](getting-started/overview.md).
- Ready to install? See [Installing](getting-started/install.md).
- Want to change something? Read [Where things are configured](system/configuration.md),
  then the page of your variant.

## d77void Immutable

d77void Immutable, a variant where the system is a read-only image updated as
a whole, has its own documentation:
[d77void Immutable Docs](https://d77void.github.io/immutable-docs/).
What is written here about installing packages and updating does **not**
apply to it.
